# nextjs-vercel-daily

Turborepo monorepo with Next.js 16 apps (web, blog) and shared packages (`@repo/ui`, `@repo/api`). Built with React 19, TypeScript, Tailwind CSS 4, and Biome.

## Quick start

```bash
pnpm install
pnpm dev
```

- **Web:** http://localhost:3000

## Scripts

| Command      | Description        |
| ------------ | ------------------ |
| `pnpm dev`   | Start dev servers  |
| `pnpm build` | Build all packages |
| `pnpm check` | Lint and format    |

See [AGENTS.md](./AGENTS.md) for full setup, Vercel CLI usage, and course notes.
